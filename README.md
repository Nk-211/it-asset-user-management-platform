# IT Asset, User & Onboarding Management Platform

A practical IT asset and user management application designed to simulate common internal IT operations such as user management, device inventory, asset assignment, onboarding and offboarding.

This project demonstrates how an IT support team can maintain visibility of users, company devices and equipment assignments through a structured system.

---

## Project Overview

IT support teams need to know:

- Which users are active
- Which department they belong to
- Which devices are assigned to them
- What operating system each device uses
- Whether equipment is available, assigned or under repair
- Which assets need to be returned during offboarding
- What equipment needs to be prepared for a new employee

This project provides a simplified local platform for managing these activities.
